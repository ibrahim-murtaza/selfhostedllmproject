**Bug Report: Cost Forecast Percentage Not Calculated**

**Summary:**
The % Percentage column in the Cost Forecast section remains at 0% for all months, despite populated monthly forecast values in Value LCY and Value USD.

**Description:**
In the Financials > Cost Forecast section, monthly forecast values are correctly populated in the Value LCY and Value USD columns. However, the corresponding % Percentage column incorrectly displays **0%** for every month, regardless of non-zero values in the currency fields. The percentage should reflect each month's forecast share based on the provided values.

**User Story:**
As a user reviewing project cost forecasts, I expect the % Percentage column to accurately reflect each month’s forecast share so I can understand the total forecast distribution across the forecast period.

**Acceptance Criteria:**
- The % Percentage column must calculate and display a valid percentage for months with forecast values.
- Non-zero Value LCY/Value USD entries must not show **0%** unless the calculated percentage is genuinely zero.
- Percentage values must align consistently with the total monthly forecast distribution.

**Steps to Reproduce:**
1. Open a project containing Project Forecast data.
2. Navigate to Financials > Cost Forecast.
3. Expand the relevant forecast year.
4. Identify months with populated Value LCY or Value USD amounts.
5. Observe the % Percentage column—it incorrectly displays **0%** for all months.

**Expected Behavior:**
The % Percentage column should dynamically calculate and display the correct forecast percentage for each month based on its allocated Value LCY/Value USD, with non-zero values correctly represented.
